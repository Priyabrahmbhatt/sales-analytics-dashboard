# Sales Analytics Dashboard

## Overview

This project analyzes a retail sales dataset containing 9,800 transactions using Python and Pandas.

The goal was to identify sales trends, top-performing regions, states, and products to support business decision-making.

## Tools Used

* Python
* Pandas
* Matplotlib
* Excel

## Key Findings

* West region generated the highest sales revenue ($710K+).
* California was the highest-performing state ($446K+).
* Canon imageCLASS 2200 Advanced Copier was the top-selling product.
* Regional sales performance showed significant differences across the United States.
